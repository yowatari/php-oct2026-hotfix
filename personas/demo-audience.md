# demo-audience

## 背景
- このリポジトリは、2026-10-21 の PHP セキュリティリリース（CVE-2026-109618 / CVE-2026-109619）に対応したイメージを自前でビルドして ghcr.io に配信するデモ
- README の目的は、このデモの良いところを伝えること

## この分野で既に知っていること（推測）
- Docker と Dockerfile、GitHub Actions、ghcr.io は普段使っている
- CVE が出たら「公式イメージの更新を待って、ベースイメージを上げる」運用をしている
- Wolfi / melange / apko / cosign は名前を聞いたことがある程度で、自分では使っていない

## 怪しいところ（推測。資料の芯になる）
- 自前でビルドすると「手間が増える・品質が下がる・安全性を自分で担保できない」と思っている。実際には、検証（sha256・署名・SBOM・スキャン）がパイプラインに入っていることを知らない
- 「スキャナが緑なら修正済み」と考えがち。このイメージはパッケージ名が独自（php-hotfix）なので、スキャナの判定は修正の証明にならない
- EOL の 7.4 にパッチを当てれば「安全になる」と受け取りがち。実際は今回の 2 件だけの最小限の緩和策
- 「速い」の中身（何分で、どこが律速か）を数字で知らない

## 知りたいこと
- 本番の `FROM` を差し替えられるか。アプリと拡張モジュールをどう載せるか
- 個人アカウントの ghcr にあるイメージを、本番で使ってよいか
- 理解度チェックは、LT の補足としては重く感じる
